# Portfolio de Miled Cherif

Un monde 3D en quatre univers (Cybersécurité, Produits SaaS, Sites & plateformes, Jeux), parcouru au scroll.

- `src/projects.js` : tout le contenu (textes, projets, captures)
- `src/main.js` : la scène Three.js, la caméra guidée et les fiches projet
- `public/captures/` : captures des projets (données de démonstration fictives)

```bash
npm install
npm run dev      # http://localhost:5173/portfolio/
npm run build    # site statique dans dist/
```

Chaque push sur `main` publie le site sur GitHub Pages.
